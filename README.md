# مطالعة

تطبيق لإنشاء الكتب الرسمية والمطالعات بصيغة Word بأمر بسيط.

- **النماذج:** ارفع كتباً سابقة (.docx) ويأخذ التطبيق منها الشعار والترويسة والخط والأسلوب.
- **المحادثة:** اكتب طلبك (مثلاً: إجازة 3 أيام للموظف علي) ويسألك عن العدد والتاريخ وأي معلومة ناقصة، ثم يطلع ملف Word بنفس شكل دائرتك.
- **بدون إنترنت:** أسئلة جاهزة لكتب الإجازة والمطالعة والطلب اللوجستي والكتاب الحر.
- **الصياغة الذكية:** بمفتاح Gemini مجاني من الإعدادات.

## التحميل
- **أندرويد:** من صفحة [Releases](../../releases/latest) حمّل `mutalaa.apk`.
- **الكمبيوتر والآيفون:** النسخة الإلكترونية من مجلد `docs` عبر GitHub Pages.
